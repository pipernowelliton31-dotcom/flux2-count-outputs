# flux2-count outputs

Public dump of experiment **result tables** from numerosity / CountGD runs (FLUX.2 Klein and MOSS-Image).

This repo contains `csv` / `json` / `jsonl`, plus **data-visualization** images (figures, plots, contact sheets, evaluation charts).

Raw **model-generated** images under `images/` and HTML gallery thumbnails under `gallery/` are omitted. Shell launchers and logs are omitted.
